# R evaluation notebooks

The notebooks in this directory reproduce the R-based evaluation of the results generated by the TEbenchmarking workflow. They are numbered according to their intended execution order.

## Prerequisites

Before running these notebooks:

1. Run the [Snakemake workflow](../../README.md) to generate the STARsolo, SoloTE, and Stellarscope results.
2. Run the scripts in [`annotation_scripts/`](../../annotation_scripts/) to generate the needed TE annotation and nomenclature conversion tables. Place them in this directory under a subdirectory called `annotation`.
3. Obtain the simulated count matrices. They can either be:
   - generated with Minnow and Splatter using the scripts in [`simulations/`](../../simulations/); or
   - downloaded as part of `data.tar.gz` from the [TEbenchmarking Zenodo record](https://doi.org/10.5281/zenodo.18772673).
4. In the setup section of the object-creation notebooks, set the input paths to the directories containing the simulated matrices and Snakemake results.

## Execution order

Run the notebooks in numerical order:

- `00_evaluation_objectCreation.ipynb` imports the simulated matrices and workflow outputs and creates the main R workspace images in `workspaces/`.
- `01`-`03` and `05`-`08` perform the evaluations used in the manuscript. These notebooks use objects saved by notebook `00`.
- `09_5kRpC_objectCreation.ipynb`, `10_20kRpC_objectCreation.ipynb`, and `11_50kRpC_objectCreation.ipynb` create objects for the sequencing-depth comparison and save them as R workspace and RDS files.
- `12_evaluation_depth_comparison.ipynb` uses the objects generated by notebooks `00` and `09`-`11` to compare sequencing depths.

Rendered versions of the main notebooks are available in [`pdf/`](pdf/).
