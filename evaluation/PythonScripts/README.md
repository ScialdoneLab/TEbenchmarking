# Python evaluation notebooks

The scripts and notebooks in this directory reproduce the read-level mapping evaluation and related quality-control analyses. The notebooks are numbered according to their suggested execution order.

## Prerequisites

Before running these notebooks:

1. Run the [Snakemake workflow](../../README.md) to generate the SoloTE and Stellarscope results, BAM files, statistics, and logs.
2. Run the scripts in [`annotation_scripts/`](../../annotation_scripts/) to generate the required TE annotation and nomenclature-conversion tables.
3. Set the result, annotation, and log paths in the setup cells of the notebooks.

## Stellarscope BAM preprocessing

Before running notebooks `01` and `02`, process the Stellarscope BAM files with [`00_filter_stellarscope_bam_bestExclude.sh`](00_filter_stellarscope_bam_bestExclude.sh). The script retains primary alignments with a non-zero posterior probability and excludes reads for which multiple alignments share the maximum posterior probability.

The script requires `samtools` and GNU `awk`. By default, it expects `<sample>_pseudobulk-updated.bam`, produced by the one-step Stellarscope workflow, and writes the processed BAM files into the same directory. For example:

```bash
./00_filter_stellarscope_bam_bestExclude.sh \
    -p old \
    -d /path/to/results/stellarscope_out/simulated_mm_RA_pseudobulk_onestep/old
```

Repeat this step for every sample and sequencing-depth dataset included in the comparison.

The pre-EM BAM is filtered separately to retain primary alignments:

```bash
samtools view -b -F 0x100 \
    old_pseudobulk-tmp_tele.bam \
    > old_pseudobulk_primary_tele.bam
```

## Execution order

- `01_bam_comparison.ipynb` compares SoloTE and Stellarscope read assignments for the main simulation and creates CSV checkpoints in `data/`.
- `02_bam_comparison_depth.ipynb` compares read assignments across sequencing depths. It uses the checkpoints created by notebook `01` and the corresponding BAM-derived tables for the 5k, 20k, and 50k reads-per-cell simulations.
- `03_mapping_stats.ipynb` summarises unique and multimapping reads from the `*_SoloTE.stats` files generated by the Snakemake workflow. It does not depend on notebooks `01` or `02`.
- `04_stellarscope_convergence.ipynb` extracts the iteration statistics from Stellarscope log files and plots EM convergence. It does not depend on the preceding notebooks.

Rendered versions of all notebooks are available in [`pdfs/`](pdfs/).
